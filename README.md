
# AI Medical Early Disease Risk Prediction

## Disclaimer

⚠️ This project is a hackathon prototype and research demonstration only.

It is **NOT** a certified medical device and must not be used for clinical diagnosis, treatment, or emergency decision-making.

Predictions generated by this system are probabilistic estimates intended for educational and experimental purposes.

---

# Project Overview

AI Medical Early Disease Risk Prediction is a production-style machine learning prototype that estimates disease risk from patient health information such as:

- Demographics
- Lifestyle habits
- Symptoms
- Vital signs
- Family history

The platform predicts whether a patient belongs to:

- Low risk
- Medium risk
- High risk

The system also provides confidence scores and forms the foundation for explainability and preventive recommendations.

# Inference

Example:

```python
from backend.inference import predict_risk

patient = {
    "age": 42,
    "sex": "Male",
    "bmi": 27.4,
    "smoking": "Yes",
    "alcohol": "No",
    "exercise_level": "Medium",
    "heart_rate": 88,
    "systolic_bp": 135,
    "diastolic_bp": 85,
    "blood_sugar": 112,
    "cholesterol": 210,
    "family_history": "Yes",
    "fatigue": "Yes",
    "fever": "No"
}

result = predict_risk(patient)

print(result)
```

# Dataset Notes

This prototype uses a synthetic tabular dataset schema containing:

- Demographics
- Symptoms
- Lifestyle data
- Vitals
- Family history
- Binary disease-risk labels

Target labels:

- 0 → Low risk
- 1 → High risk

Real medical datasets should replace synthetic data for production research.
